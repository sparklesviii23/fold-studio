# K-562 paired-activation research prototype

User authorized reusing existing data, basic checks, a reserved test set and one small local prototype. Implementation `3545cb3` is an isolated CLI research feature, not a new default Virtual Cell predictor.

- Pinned Norman 2019/scPerturb raw file reused read-only: 111,445 cells × 33,694 genes, SHA-256 efde6f5301fe256725dce1d980f37bd96a13481a9a16135515897368e631affc; published MD5 matched. No model or dataset download, cloud allocation, Fab work or subagent.
- Frozen canonical pair groups: 77 train, 26 validation, 26 test; 102 measured single-activation calibrations. Whole conditions and all their cells/guide orders stay together. Five source conditions excluded by predeclared cell-count/identity/component-calibration rules. Eight loading groups have matched controls. This previously benchmarked public screen is retrospective, not a globally new or independent-study test.
- Source raw counts are checked for finite nonnegative integers and recorded library-size agreement. RNA normalization is per-cell log1p(counts per 10,000); loading-group control means are subtracted. Training-only variation plus target IDs selects 2,132 genes. Both activated genes are excluded from each condition's primary score.
- A symmetric, 988-parameter residual tanh MLP predicts departures from a training-fitted additive baseline, using PCA of measured component responses and a training-only residual decoder. Two fixed regularization settings and validation-only early stopping; predictions and weights sealed before the single held-out response aggregation. No further fitting after test results.
- Validation selected the neural prototype; the best validation simple baseline was scaled additivity. Test MSE: unchanged .02223808, mean pair .01205365, additive .00518960, scaled additive .00508646, neural .00379884. Neural mean response Pearson .91050 versus additive/scaled .88652. The point reduction versus the validation-selected baseline is 25.31%, but the shared-target endpoint-weighted paired MSE interval [-.00238193,+.00001280] crosses zero. A reliable improvement is not established. No automatic promotion, independent-study claim, temporal prediction or learned whole-cell state claim.
- Seven meaningful checks pass, including finite-difference gradients, holdout-statistic isolation, canonical split identities, seal-before-test, source tampering, pair-order invariance and a synthetic full workflow. Independent NumPy-only inference in a fresh process (NumPy 2.5.4) reproduces the real sealed predictions within 4.45e-16 maximum absolute difference. Raw-source hash, model hash and training-code hash remain intact.
- Completed local controller job ab4d920cc9714f9e8933b4aa150eef49: exit 0, 13 real result files, approximately 36 seconds. Installed native Virtual Cell → Runs & terminal was verified to show its completion and files. Existing production app was not rebuilt or replaced for this research feature.

Deliverables live in the task's outputs/stage3/k562-pair-prototype: REPORT.md, RESULTS.png, MODEL.npz, predict.py, MODEL_CARD.json, SPLIT_MANIFEST.json, DATA_AUDIT.json, TRAINING_LOCK.json, TRAINING_TRACE.csv, SEALED_TEST_PREDICTIONS.npz, TEST_OBSERVATIONS.npz, EVALUATION.json and METRICS.csv. The run controller retains copies with checksums. Extra verification is in outputs/stage3/VALIDATION_RECEIPT.json and PROTOTYPE_TESTS.log.

Inference requires two genes with measured single-response calibration in this specific CRISPRa screen. It does not support arbitrary unseen genes, drugs, knockouts, parental K-562 states, new cell types, intervention sequences, protein/morphology readouts or time dynamics. The same 26 test pairs must not be reused to claim a fresh untouched benchmark after further tuning.
