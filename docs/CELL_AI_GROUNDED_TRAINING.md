## Model comparisons and learning

Five candidates: direct numerical network, Cell2Sentence + numerical network, grounded Qwen, matched Qwen with adapters fixed during response learning, and Qwen + Cell2Sentence representations. The original numerical RNA expert stays inside the neural model as a protected pair-response reference. Qwen has 409,600 trainable internal attention-adapter parameters (four layers/rank 16), plus learned cell/input encoders and independent full-gene response heads. The original Qwen base remains frozen. No fixed rank-12 correction decoder.

The official [Cell2Sentence Pythia-410M model](https://huggingface.co/vandijklab/C2S-Pythia-410m-diverse-single-and-multi-cell-tasks), revision `51f7c9d46776273ea4732ddaf494d1db733ca5d6`, supplies frozen measured-input embeddings inside Qwen's numerical prefix. Weights are CC BY 4.0, attributed to the van Dijk Lab. This transfers representations; it does not concatenate unrelated checkpoint weights or reproduce the complete published model's accuracy. State/PIE architecture ideas informed the design; their weights/models are not installed by this change. GB.Cell outputs are not distilled into this model.

One full foundation pass precedes balanced response-task learning. Each task has its own validation score, early stopping, selected epoch and complete task checkpoint. Up to 12 response epochs, patience four, one seed in this pilot. Non-reentrant gradient checkpointing reduces memory use. Numerical baselines include unchanged, training mean and validation-selected ridge using all available raw/structured/biology inputs. Baseline coefficients and nonselected candidate checkpoints remain in the remote archive; selected neural checkpoints and predictions return locally.

Evaluation includes full-panel MSE/MAE, effect cosine, undefined-safe correlation, top-effect magnitude/direction/overlap, signature discrimination and paired bootstrap intervals over intervention groups. Statistical DE calls and calibrated individual prediction intervals are not claimed. Final predictions are sealed before local answer opening; validation determines the winner including baselines. No app default is automatically promoted. This remains an RNA-response research pipeline, not a validated whole-cell simulator.
