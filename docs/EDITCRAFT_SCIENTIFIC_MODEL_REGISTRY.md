Registry of record: `scientific/editcraft-models.json`. Exact upstream assets, sizes and pinned Git blob identities: `remote_worker/fold_rapid/editcraft_assets.json`. These manifests contain no trained weights. The macOS app stores no new scientific model installations.

The isolated Linux model environments keep historical dependency versions separate from the existing core Python 3.12/Biopython 1.85 runtime. Input validation runs before upload. Trained inference verifies every source and checkpoint against the pinned manifest and recorded SHA-256 before trusted upstream pickle loading. No missing model yields a substitute prediction.

PrimeDesign has upstream dual academic/for-profit terms; eligibility and implementation remain unresolved. BE-Hive refers to separate website terms; permission has not been established by repository visibility. DeepPrime/PRIDICT/GenET have pinned repository discovery records but incomplete scientific API/license/runtime audits. All other requested methods remain explicitly unresolved in the JSON registry; their names are not executing integrations.

Original EditCraft Intelligence has no trained model, calibration benchmark or demonstrated adaptive optimization. The current fixed typed workflow is not represented as such a system.

The pinned PRIDICT2 parser checks flanks of at least 99 nt (`pridict2_pegRNA_design.py` lines 531–533), and its official README example uses 99 upstream bases despite prose stating 100. The adapter follows the explicit source contract and preserves the official example unchanged. No missing base is fabricated.
